# 0392. Is Subsequence

- **Сложность:** Easy
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №392](https://leetcode.com/problems/is-subsequence/)

## Идея
Используем два указателя: `sIndex` для целевой подпоследовательности `s` и `tIndex` для исходной строки `t`.
1. Проходим по строке `t`. При совпадении символов `s[sIndex] == t[tIndex]` сдвигаем указатель `sIndex`.
2. Указатель `tIndex` увеличивается на каждой итерации.
3. Если в конце `sIndex` достиг длины строки `s`, значит, все её символы встретились в строке `t` с сохранением порядка.

## Сложность
- **Time Complexity:** $O(T)$, где $T$ — длина строки `t`. В худшем случае мы совершаем один проход по длинной строке.
- **Space Complexity:** $O(1)$ — дополнительная память под структуры данных не выделяется.
