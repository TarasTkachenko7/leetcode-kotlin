# 0167. Two Sum II - Input Array Is Sorted

- **Сложность:** Medium
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №167](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/)

## Идея
Так как массив уже отсортирован по возрастанию, можно использовать технику двух указателей с обоих концов массива:
1. Если текущая сумма меньше `target`, увеличиваем `left`, чтобы получить большее значение.
2. Если текущая сумма больше `target`, уменьшаем `right`, чтобы получить меньшее значение.
3. По условию задачи индексация начинается с 1 (1-indexed), поэтому к найденным индексам прибавляем `1`.

## Сложность
- **Time Complexity:** $O(N)$ — в худшем случае каждый элемент массива просматривается один раз.
- **Space Complexity:** $O(1)$ — дополнительная память не используется.
