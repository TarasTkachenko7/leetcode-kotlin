# 0844. Backspace String Compare

- **Сложность:** Easy
- **Паттерн:** Two Pointers (Reverse Traversal)
- **Ссылка:** [LeetCode №844](https://leetcode.com/problems/backspace-string-compare/)

## Идея
Символ `#` стирает символ слева от себя, поэтому прямой обход усложняет вычисления. Проще идти с конца обеих строк:
1. Используем счетчики `skipS` и `skipT` для накопления количества символов `#`.
2. Если встречаем обычный символ при ненулевом счетчике `skip`, просто пропускаем его и декрементируем счетчик.
3. Дойдя до фактических символов, которые останутся в итоговой строке, сравниваем их:
    - Если символы различаются — строки не равны.
    - Если в одной строке символы закончились, а в другой еще есть — строки не равны.
4. Повторяем процесс, пока обе строки не будут полностью обработаны.

## Сложность
- **Time Complexity:** $O(N + M)$, где $N$ и $M$ — длины строк `s` и `t`. Каждая строка просматривается один раз.
- **Space Complexity:** $O(1)$ — сравнение выполняется на лету без аллокации стека или новых строк.
