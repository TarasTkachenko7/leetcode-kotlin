# 0287. Find the Duplicate Number

- **Сложность:** Medium
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №287](https://leetcode.com/problems/find-the-duplicate-number/)

## Идея
По условию массив длины $n + 1$ содержит числа от $1$ до $n$. Это позволяет рассматривать массив как односвязный список, где переход к следующему узлу задается как `next = nums[curr]`. Наличие дублирующегося числа означает, что на один и тот же индекс ссылаются два разных элемента — образуется цикл.

Решение состоит из двух фаз алгоритма Флойда:
1. **Обнаружение цикла:** `slow` делает 1 переход (`nums[slow]`), `fast` делает 2 перехода (`nums[nums[fast]]`). Они гарантированно встречаются внутри цикла.
2. **Поиск точки входа:** помещаем `ptr1` в начало массива (`nums[0]`), а `ptr2` оставляем в точке встречи. Двигаем оба указателя с одинаковой скоростью по 1 шагу. Точка их встречи — начало цикла, то есть повторяющееся число.

## Сложность
- **Time Complexity:** $O(N)$ — обе фазы алгоритма завершаются за линейное время.
- **Space Complexity:** $O(1)$ — дополнительная память под структуры данных не выделяется, исходный массив не изменяется.
