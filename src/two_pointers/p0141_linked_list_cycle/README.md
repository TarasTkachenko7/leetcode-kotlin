# 0141. Linked List Cycle

- **Сложность:** Easy
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №141](https://leetcode.com/problems/linked-list-cycle/)

## Идея
Для определения зацикленности связного списка без выделения дополнительной памяти ($O(1)$ Space) используется алгоритм Флойда:
1. Задаем два указателя: `slow` (двигается на 1 шаг за итерацию) и `fast` (двигается на 2 шага).
2. Если в списке нет цикла, быстрый указатель `fast` первым достигнет `null`.
3. Если цикл существует, `fast` окажется внутри кольца и начнет сокращать дистанцию до `slow` на 1 узел на каждом шаге, в итоге указатели гарантированно встретятся (`fast === slow`).

## Сложность
- **Time Complexity:** $O(N)$ — если цикла нет, `fast` дойдет до конца за $N/2$ итераций. Если цикл есть, указатели встретятся максимум за время, пропорциональное числу узлов.
- **Space Complexity:** $O(1)$ — используются только два указателя без создания дополнительных коллекций (`HashSet`).
