# 0977. Squares of a Sorted Array

- **Сложность:** Easy
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode #977](https://leetcode.com/problems/squares-of-a-sorted-array/)

## Идея
Исходный массив уже отсортирован, но может содержать отрицательные числа. Квадраты наибольших по модулю чисел будут находиться либо в самом начале (большие отрицательные), либо в самом конце (большие положительные).

Используем два указателя (`left` и `right`):
1. Сравниваем квадраты элементов на концах массива.
2. Больший квадрат помещаем в конец результирующего массива (`insertIndex`).
3. Сдвигаем соответствующий указатель внутрь и уменьшаем `insertIndex`.

## Сложность
- **Time Complexity:** $O(N)$ — однократный проход по массиву длины $N$ без вызова отдельной сортировки.
- **Space Complexity:** $O(N)$ — под возвращаемый результат (или $O(1)$ дополнительной памяти, если не считать массив ответа).
