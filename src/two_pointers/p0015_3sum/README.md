# 0015. 3Sum

- **Сложность:** Medium
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №15](https://leetcode.com/problems/3sum/)

## Идея
1. Сортируем входной массив. Это позволяет свести поиск трёх чисел к комбинации внешнего цикла и паттерна двух указателей.
2. Фиксируем первый элемент `nums[i]`. Если `nums[i] > 0`, дальнейший поиск бессмысленен, так как все последующие числа также положительны.
3. Оставшуюся пару ищем двумя указателями (`left` и `right`), целясь в сумму `-nums[i]`.
4. Для исключения повторяющихся троек обязательно пропускаем дублирующиеся элементы как для внешнего цикла, так и при сдвиге указателей после нахождения ответа.

## Сложность
- **Time Complexity:** $O(N^2)$ — сортировка занимает $O(N \log N)$, а вложенный проход двух указателей для каждого элемента занимает $O(N^2)$.
- **Space Complexity:** $O(1)$ (или $O(\log N)$ в зависимости от реализации встроенной сортировки), если не учитывать память под результирующий список.
