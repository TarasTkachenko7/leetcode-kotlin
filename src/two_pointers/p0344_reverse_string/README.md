# 0344. Reverse String

- **Сложность:** Easy
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №344](https://leetcode.com/problems/reverse-string/)

## Идея
Используем два указателя с противоположных концов массива (`left` и `right`).
Пока указатели не встретятся, меняем символы местами и сдвигаем указатели навстречу друг другу. Модификация выполняется in-place без выделения дополнительной памяти.

## Сложность
- **Time Complexity:** $O(N)$ — совершается $N/2$ итераций, где $N$ — длина массива.
- **Space Complexity:** $O(1)$ — замена элементов на месте без создания копий массива.
