# 0088. Merge Sorted Array

- **Сложность:** Easy
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №88](https://leetcode.com/problems/merge-sorted-array/)

## Идея
Так как массив `nums1` имеет достаточный размер для хранения элементов обоих массивов ($m + n$), слияние с начала потребовало бы сдвигов элементов или создания копии массива.
Вместо этого используем три указателя и идем с конца:
1. `mIndex` указывает на последний валидный элемент в `nums1`.
2. `nIndex` указывает на последний элемент в `nums2`.
3. `index` указывает на текущую позицию записи с конца `nums1`.
4. Сравниваем наибольшие доступные элементы и записываем больший в конец. Цикл продолжается, пока не закончатся элементы `nums2` (если элементы `nums2` исчерпаны, оставшиеся элементы `nums1` уже стоят на своих местах).

## Сложность
- **Time Complexity:** $O(m + n)$ — каждый элемент обоих массивов просматривается не более одного раза.
- **Space Complexity:** $O(1)$ — слияние выполняется in-place.
