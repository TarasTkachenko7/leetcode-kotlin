# 0026. Remove Duplicates from Sorted Array

- **Сложность:** Easy
- **Паттерн:** Two Pointers (Fast & Slow)
- **Ссылка:** [LeetCode №26](https://leetcode.com/problems/remove-duplicates-from-sorted-array/)

## Идея
Так как массив уже отсортирован, все одинаковые элементы стоят рядом.
Используем два указателя:
1. `insertIndex` (медленный) — указывает позицию, куда нужно записать следующий уникальный элемент.
2. `i` (быстрый) — бежит по массиву и сравнивает текущий элемент с предыдущим `nums[i] != nums[i - 1]`.
3. При обнаружении нового уникального числа записываем его по адресу `nums[insertIndex]` и увеличиваем `insertIndex`.

## Сложность
- **Time Complexity:** $O(N)$ — однократный проход по массиву длины $N$.
- **Space Complexity:** $O(1)$ — модификация выполняется in-place без выделения дополнительной памяти.
