# 0283. Move Zeroes

- **Сложность:** Easy
- **Паттерн:** Two Pointers (Fast & Slow)
- **Ссылка:** [LeetCode №283](https://leetcode.com/problems/move-zeroes/)

## Идея
Используем два указателя для перемещения элементов на месте без создания копии массива:
1. `insertIndex` указывает на позицию, куда должен быть помещен следующий ненулевой элемент.
2. `i` сканирует массив в поисках чисел, отличных от нуля.
3. При нахождении ненулевого элемента меняем его местами с элементом по индексу `insertIndex` (только если индексы не совпадают) и увеличиваем `insertIndex`.

## Сложность
- **Time Complexity:** $O(N)$ — однократный проход по массиву длины $N$.
- **Space Complexity:** $O(1)$ — перемещение выполняется in-place.
