# 0075. Sort Colors

- **Сложность:** Medium
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №75](https://leetcode.com/problems/sort-colors/)

## Идея
Классический алгоритм трёхстороннего разбиения (флаг Нидерландов) делит массив на четыре сегмента:
- `[0 .. low - 1]` — нули;
- `[low .. mid - 1]` — единицы;
- `[mid .. high]` — неисследованная зона;
- `[high + 1 .. n - 1]` — двойки.

Двигаем указатель `mid`:
1. Если `nums[mid] == 0`: меняем местами с `nums[low]`, двигаем оба указателя (`low++`, `mid++`).
2. Если `nums[mid] == 1`: элемент на своём месте, двигаем только `mid++`.
3. Если `nums[mid] == 2`: меняем местами с `nums[high]`, сдвигаем только `high--`. Указатель `mid` остаётся на месте, так как пришедший из конца элемент ещё не проверен.

## Сложность
- **Time Complexity:** $O(N)$ — строго один проход по массиву.
- **Space Complexity:** $O(1)$ — сортировка выполняется на месте без дополнительной памяти.
