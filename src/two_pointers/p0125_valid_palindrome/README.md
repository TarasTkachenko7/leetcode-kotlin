# 0125. Valid Palindrome

- **Сложность:** Easy
- **Паттерн:** Two Pointers
- **Ссылка:** [LeetCode №125](https://leetcode.com/problems/valid-palindrome/)

## Идея
Используем два указателя с противоположных концов строки.
Пропускаем любые не буквенно-цифровые символы с помощью `isLetterOrDigit()`. При обнаружении валидных символов сравниваем их в нижнем регистре. Если символы не совпали — строка не палиндром.

## Сложность
- **Time Complexity:** $O(N)$ — однократный проход по строке длиной $N$.
- **Space Complexity:** $O(1)$ — проверка выполняется без создания дополнительной копии строки в памяти.
