# 0349. Intersection of Two Arrays

- **Сложность:** Easy
- **Паттерн:** HashSet
- **Ссылка:** [LeetCode №349](https://leetcode.com/problems/intersection-of-two-arrays/)

## Идея
Определяем массив меньшего размера и добавляем его значения в `HashSet`. Затем проходим по большему массиву. Если `remaining.remove(number)` возвращает `true`, число есть в обоих массивах: добавляем его в результат. Удаление одновременно гарантирует, что каждое общее число попадёт в ответ только один раз.

Результат собирается в список, а перед возвратом преобразуется в `IntArray`.

## Сложность
- **Time Complexity:** $O(n + m)$ в среднем: один проход для заполнения множества и один проход по большему массиву; операции `HashSet` выполняются за $O(1)$ в среднем.
- **Space Complexity:** $O(\min(n, m))$: множество строится по меньшему массиву, а размер результата не превышает число уникальных значений в нём.
