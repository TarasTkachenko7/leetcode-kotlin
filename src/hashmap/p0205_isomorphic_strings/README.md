# 0205. Isomorphic Strings

- **Сложность:** Easy
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №205](https://leetcode.com/problems/isomorphic-strings/)

## Идея
Используем две хэш-таблицы, чтобы проверить взаимно-однозначное соответствие символов:
1. Если длины строк различаются, сразу возвращаем `false`.
2. Для каждой позиции проверяем соответствие `s[i] -> t[i]` и обратное `t[i] -> s[i]`. Если уже сохранённое соответствие противоречит текущей паре, возвращаем `false`.
3. Сохраняем текущую пару в обеих таблицах. Если противоречий нет, строки изоморфны.

## Сложность
- **Time Complexity:** $O(N)$ — один проход по строкам; операции хэш-таблицы выполняются за $O(1)$ в среднем.
- **Space Complexity:** $O(K)$ — для двух таблиц хранятся соответствия между различными символами, где $K$ — число различных символов. При ограничении ASCII алфавит фиксирован, поэтому это $O(1)$.
