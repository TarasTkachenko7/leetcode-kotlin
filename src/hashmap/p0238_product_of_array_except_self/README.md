# 0238. Product of Array Except Self

- **Сложность:** Medium
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №238](https://leetcode.com/problems/product-of-array-except-self/)

## Идея
Для каждого элемента `nums[i]` его произведение со всеми остальными элементами равно произведению всех элементов слева (префикс) на произведение всех элементов справа (постфикс):
1. Инициализируем массив `result` размером `nums.size`.
2. **Префиксный проход (слева направо):**
    - На шаге `i` записываем в `result[i]` накопленное произведение всех элементов левее `i` (`prefix`).
    - Домножаем `prefix *= nums[i]`.
3. **Постфиксный проход (справа налево):**
    - Проходим с конца через `nums.indices.reversed()`.
    - Домножаем уже лежащее в `result[i]` значение префикса на накопленный постфикс: `result[i] *= postfix`.
    - Домножаем `postfix *= nums[i]`.
4. В результате каждый элемент получает значение `(произведение слева) * (произведение справа)` без использования операции деления.

## Сложность
- **Time Complexity:** $O(N)$ — два последовательных линейных прохода по массиву.
- **Space Complexity:** $O(1)$ — дополнительная память не расходуется, так как вычисления проводятся непосредственно в возвращаемом массиве `result`.
