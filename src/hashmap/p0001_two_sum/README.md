# 0001. Two Sum

- **Сложность:** Easy
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №1](https://leetcode.com/problems/two-sum/)

## Идея
Решение через однопроходную хэш-таблицу:
1. Итерируемся по массиву в диапазоне `0..nums.lastIndex`.
2. Для каждого числа вычисляем парное слагаемое: `complement = target - nums[i]`.
3. Если `complement` уже есть в мапе, возвращаем пару индексов `[map[complement]!, i]`.
4. В противном случае записываем текущее значение и его позицию в мапу: `map[nums[i]] = i`.

## Сложность
- **Time Complexity:** $O(N)$ — один линейный проход по массиву с поиском в хэш-таблице за $O(1)$ в среднем.
- **Space Complexity:** $O(N)$ — память под хранение до $N$ элементов в хэш-таблице.
