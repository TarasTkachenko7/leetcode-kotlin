# 0347. Top K Frequent Elements

- **Сложность:** Medium
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №347](https://leetcode.com/problems/top-k-frequent-elements/)

## Идея
Для достижения строго линейного времени $O(N)$ вместо сортировки или кучи ($O(N \log K)$) используется алгоритм блочной сортировки (**Bucket Sort**):
1. Подсчитываем частоту появления каждого числа с помощью `frequencyMap`.
2. Создаем массив списков `buckets` размером `nums.size + 1`, где индексом выступает частота появления, а элементами — числа с данной частотой (так как максимальная возможная частота не превосходит длины массива `nums`).
3. Заполняем корзины: для каждой пары `(num, count)` добавляем `num` в `buckets[count]`.
4. Итерируемся по корзинам с конца (`buckets.indices.reversed()`) и собираем первые $K$ наиболее частых чисел в итоговый массив `result`.

## Сложность
- **Time Complexity:** $O(N)$, где $N$ — размер входного массива `nums`. Подсчёт частот, распределение по корзинам и обратный обход суммарно выполняются за линейное время.
- **Space Complexity:** $O(N)$ — память для хранения карты частот `frequencyMap` и массива корзин `buckets`.
