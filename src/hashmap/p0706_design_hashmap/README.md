# 0706. Design HashMap

- **Сложность:** Easy
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №706](https://leetcode.com/problems/design-hashmap/)

## Идея
Реализация хэш-таблицы методом цепочек (Separate Chaining) на базе связных списков:
1. Создаем массив корзин фиксированной емкости $M = 2069$ (простое число для минимизации коллизий при модульном хэшировании).
2. Каждая корзина инициализируется фиктивным узлом-заглушкой `Node(-1, -1)`, что устраняет необходимость специальных проверок при добавлении в голову или удалении головы списка.
3. Вспомогательный метод `findPrev(head, key)` возвращает узел, предшествующий искомому элементу с ключом `key`.
4. **`put(key, value)`**: если узел найден — обновляем значение, если нет (`prev.next == null`) — вставляем новый узел в конец цепочки.
5. **`get(key)`**: возвращаем `prev.next?.value ?: -1`.
6. **`remove(key)`**: если элемент существует, исключаем его перебрасыванием ссылки `prev.next = prev.next.next`.

## Сложность
- **Time Complexity:**
    - $O(1)$ в среднем для `put`, `get` и `remove`.
    - $O(N / M)$ в худшем случае при возникновении коллизий (длина цепочки).
- **Space Complexity:** $O(N + M)$, где $M$ — количество корзин ($2069$), а $N$ — число уникальных сохранённых ключей.
