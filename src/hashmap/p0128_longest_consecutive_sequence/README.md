# 0128. Longest Consecutive Sequence

- **Сложность:** Medium
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №128](https://leetcode.com/problems/longest-consecutive-sequence/)

## Идея
Требуется найти длину наибольшей последовательности идущих подряд чисел за $O(N)$ времени (что исключает стандартную сортировку за $O(N \log N)$):
1. Помещаем все элементы массива в `HashSet` для проверки существования элементов за $O(1)$ в среднем.
2. Итерируемся по множеству `set`. Чтобы не совершать лишних проверок, начинаем подсчёт длины последовательности только от **начала цепи**:
    - Число `num` является началом последовательности, если `(num - 1) !in set`.
3. Если начало найдено, увеличиваем `currentNum` на 1 в цикле `while ((currentNum + 1) in set)` и инкрементируем счетчик текущей длины `currentStreak`.
4. Обновляем глобальный максимум `longest = maxOf(longest, currentStreak)`.
5. Благодаря проверке `(num - 1) !in set`, каждый элемент массива участвует во внутреннем цикле не более одного раза.

## Сложность
- **Time Complexity:** $O(N)$ — добавление элементов в `HashSet` занимает $O(N)$. Каждый элемент проверяется как кандидат на начало последовательности за $O(1)$ и обрабатывается во внутреннем цикле максимум один раз.
- **Space Complexity:** $O(N)$ — память для хранения уникальных чисел в `HashSet`.
