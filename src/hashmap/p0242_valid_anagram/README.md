# 0242. Valid Anagram

- **Сложность:** Easy
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №242](https://leetcode.com/problems/valid-anagram/)

## Идея
Строка $t$ является анаграммой строки $s$, если они состоят из одного и того же набора символов одинаковой частоты:
1. Если длины строк не совпадают (`s.length != t.length`), они заведомо не анаграммы — сразу возвращаем `false`.
2. Используем массив фиксированной длины `IntArray(26)` в качестве частотной таблицы для латинских букв в нижнем регистре.
3. Проходим по индексам строк за один цикл:
    - Инкрементируем счетчик для символа из $s$: `alphabet[sChar - 'a']++`.
    - Декрементируем счетчик для символа из $t$: `alphabet[tChar - 'a']--`.
4. Если строки являются анаграммами, частоты всех символов скомпенсируются в 0. Проверяем условие через `alphabet.all { it == 0 }`.

## Сложность
- **Time Complexity:** $O(N)$, где $N$ — длина строки. Один проход по строке и финальная проверка массива длины 26 ($O(1)$).
- **Space Complexity:** $O(1)$ — размер массива частот строго фиксирован (26 элементов) и не зависит от размера входных данных.
