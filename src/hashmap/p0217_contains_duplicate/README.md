# 0217. Contains Duplicate

- **Сложность:** Easy
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №217](https://leetcode.com/problems/contains-duplicate/)

## Идея
Для поиска повторяющихся значений за линейное время используется хэш-таблица (`HashSet`):
1. Инициализируем пустое множество `seen` для хранения уже встреченных чисел.
2. Последовательно итерируемся по массиву `nums`:
    - Если текущее число `num` уже содержится во множестве (`num in seen`), значит найден дубликат — немедленно возвращаем `true`.
    - Если числа еще нет, добавляем его в `seen`.
3. Если цикл завершился и дубликатов не обнаружено, возвращаем `false`.

## Сложность
- **Time Complexity:** $O(N)$ — однократный проход по массиву длины $N$, где операции поиска и вставки в `HashSet` занимают $O(1)$ в среднем.
- **Space Complexity:** $O(N)$ — память для хранения до $N$ уникальных элементов во множестве `seen`.
