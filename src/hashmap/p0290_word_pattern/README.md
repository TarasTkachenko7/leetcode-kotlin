# 0290. Word Pattern

- **Сложность:** Easy
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №290](https://leetcode.com/problems/word-pattern/)

## Идея
Храним соответствие от буквы паттерна к слову в одной хэш-таблице:
1. Разбиваем строку `s` на слова и проверяем, что их количество равно длине `pattern`.
2. Для каждой пары «буква — слово» смотрим, есть ли буква в `map`. Если есть, слово должно совпадать с сохранённым.
3. Если буква новая, проверяем `map.containsValue(word)`: слово не должно быть значением другой буквы. Если оно ещё не занято, сохраняем пару.

## Сложность
- **Time Complexity:** $O(P + M)$ при ограничении задачи на 26 строчных букв: `split` проходит по строке длины $M$, а `containsValue` вызывается только для новых букв и сканирует не более 26 соответствий.
- **Space Complexity:** $O(M + K)$ — список слов занимает до $O(M)$ памяти, а `map` хранит до $K$ соответствий, где $K \le 26$.
