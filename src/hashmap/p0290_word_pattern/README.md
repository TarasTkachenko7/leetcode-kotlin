# 0290. Word Pattern

- **Сложность:** Easy
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №290](https://leetcode.com/problems/word-pattern/)

## Идея
Используем две хэш-таблицы для взаимно-однозначного соответствия букв и слов:
1. Разбиваем строку `s` на слова и проверяем, что их количество равно длине `pattern`.
2. Для каждой пары «буква — слово» проверяем прямое соответствие `patternToS[from] -> to` и обратное `sToPattern[to] -> from`.
3. Если хотя бы одно сохранённое соответствие конфликтует с текущей парой, возвращаем `false`; иначе записываем пару в обе таблицы.

## Сложность
- **Time Complexity:** $O(P + M)$ в среднем — `split` проходит по строке длины $M$, затем выполняется один проход по $P$ буквам с ожидаемыми операциями хэш-таблиц за $O(1)$.
- **Space Complexity:** $O(M + K)$ — список слов занимает до $O(M)$ памяти, а две таблицы хранят до $K$ соответствий, где $K$ — число различных букв в `pattern`.
