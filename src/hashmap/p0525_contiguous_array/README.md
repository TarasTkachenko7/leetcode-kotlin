# 0525. Contiguous Array

- **Сложность:** Medium
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №525](https://leetcode.com/problems/contiguous-array/)

## Идея
Для поиска подмассива с равным количеством `0` и `1` преобразуем задачу в поиск подмассива с суммой `0`:
1. Считаем каждый `0` за `-1`, а `1` за `+1`.
2. Если на индексах $i$ и $j$ ($i < j$) префиксная сумма одинакова, то сумма элементов подмассива от $i + 1$ до $j$ равна $0$, а значит, число нулей и единиц на этом отрезке совпадает.
3. Используем `map`, где ключ — префиксная сумма, а значение — **самый ранний** индекс, на котором она встретилась.
4. Инициализируем `map[0] = -1`, чтобы корректно учитывать подмассивы, сбалансированные от самого начала массива.
5. Для каждого шага:
    - Если сумма встретилась впервые, записываем ее индекс `map[currentSum] = i`.
    - Если сумма уже была в таблице, не перезаписываем её (чтобы максимизировать длину отрезка), а вычисляем длину `i - map[currentSum]` и обновляем глобальный `maxLength`.

## Сложность
- **Time Complexity:** $O(N)$ — один проход по массиву длины $N$, операции поиска и вставки в хэш-таблицу выполняются в среднем за $O(1)$.
- **Space Complexity:** $O(N)$ — память для хранения до $N$ уникальных значений префиксных сумм в `map`.
