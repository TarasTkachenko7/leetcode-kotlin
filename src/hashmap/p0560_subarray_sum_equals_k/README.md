# 0560. Subarray Sum Equals K

- **Сложность:** Medium
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №560](https://leetcode.com/problems/subarray-sum-equals-k/)

## Идея
Сумма подмассива от индекса $i$ до $j$ выражается через разность префиксных сумм: $\text{sum}(i, j) = \text{prefix}[j] - \text{prefix}[i - 1]$.
Если $\text{sum}(i, j) = k$, то $\text{prefix}[j] - k = \text{prefix}[i - 1]$.
1. Используем `prefixMap`, где ключ — значение префиксной суммы, а значение — количество раз, сколько данная сумма встречалась ранее.
2. Инициализируем `prefixMap[0] = 1`, чтобы учесть случай, когда непрерывный подмассив от самого начала массива имеет сумму, равную $k$.
3. Итерируемся по массиву, накапливая текущую сумму `currentSum += num`.
4. Ищем в таблице целевую разность `target = currentSum - k`. Если такая префиксная сумма уже встречалась, прибавляем количество её вхождений к ответу: `count += prefixMap[target]`.
5. Добавляем текущую накопленную сумму `currentSum` в `prefixMap`.

## Сложность
- **Time Complexity:** $O(N)$ — один проход по массиву $N$ с поиском и обновлением хэш-таблицы за $O(1)$ в среднем.
- **Space Complexity:** $O(N)$ — память для хранения до $N$ уникальных значений префиксных сумм в `prefixMap`.
