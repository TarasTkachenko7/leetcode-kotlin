# 0049. Group Anagrams

- **Сложность:** Medium
- **Паттерн:** HashMap
- **Ссылка:** [LeetCode №49](https://leetcode.com/problems/group-anagrams/)

## Идея
Строки являются анаграммами тогда и только тогда, когда частоты входящих в них символов совпадают.
1. Для каждой строки формируем уникальный сигнатурный ключ на основе подсчёта частот символов:
    - Массив `IntArray(26)` считает вхождения каждой буквы английского алфавита.
    - Преобразуем массив в строку вида `#1#0#2...`, разделяя частоты символом `#` во избежание коллизий (например, между 1 и 10).
2. Используем `HashMap<String, MutableList<String>>`, где ключ — полученная сигнатура частот, а значение — список слов, соответствующих этому паттерну.
3. Добавляем каждое слово в соответствующий бакет через `getOrPut`.
4. В конце возвращаем все сгруппированные списки через `map.values.toList()`.

## Сложность
- **Time Complexity:** $O(N \cdot K)$, где $N$ — количество строк, а $K$ — максимальная длина строки. Подсчет частот и формирование ключа занимают $O(K + 26) = O(K)$.
- **Space Complexity:** $O(N \cdot K)$ — память под хранение ключей и сгруппированных строк в `HashMap`.
