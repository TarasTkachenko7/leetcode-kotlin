# 0036. Valid Sudoku

- **Сложность:** Medium
- **Паттерн:** HashSet / Matrix Validation
- **Ссылка:** [LeetCode №36](https://leetcode.com/problems/valid-sudoku/)

## Идея
Для строк, столбцов и квадратов 3×3 заводим отдельные наборы `HashSet`:
1. Проходим по всем клеткам доски и пропускаем пустые (`'.'`).
2. Для заполненной клетки вычисляем индекс её квадрата 3×3: `(i / 3) * 3 + j / 3`.
3. Добавляем цифру в набор строки, столбца и квадрата. Если `add` хотя бы для одного набора возвращает `false`, цифра там уже встречалась и доска некорректна.
4. Если весь проход завершился без повторов, возвращаем `true`.

## Сложность
- **Time Complexity:** $O(1)$ для фиксированной доски 9×9; для обобщённой доски N×N проход занимает $O(N^2)$ в среднем.
- **Space Complexity:** $O(1)$ для фиксированной доски 9×9; для обобщённой доски наборы хранят до $O(N^2)$ записей.
