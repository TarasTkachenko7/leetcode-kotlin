# 0033. Search in Rotated Sorted Array

- **Сложность:** Medium
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №33](https://leetcode.com/problems/search-in-rotated-sorted-array/)

## Идея
Массив отсортирован по возрастанию с уникальными значениями и циклически сдвинут в неизвестной точке:
1. Ключевое свойство сдвинутого массива: середина `mid` всегда делит массив на две части, из которых как минимум одна монотонно возрастает.
2. Проверяем, какая из половин отсортирована:
    - Если `nums[mid] > nums[right]`, строго отсортирована **левая половина** $[left, mid]$. Проверяем, попадает ли `target` в границы этой половины (`nums[left] <= target < nums[mid]`): если да, сужаем поиск влево (`right = mid - 1`), иначе ищем в правой половине (`left = mid + 1`).
    - Если `nums[mid] <= nums[right]`, строго отсортирована **правая половина** $[mid, right]$. Проверяем, попадает ли `target` в её пределы (`nums[mid] < target <= nums[right]`): если да, смещаемся вправо (`left = mid + 1`), иначе влево (`right = mid - 1`).
3. Если элемент не найден при схождении границ (`left > right`), возвращаем `-1`.

## Сложность
- **Time Complexity:** $O(\log N)$ — область поиска делится пополам на каждой итерации.
- **Space Complexity:** $O(1)$ — дополнительная память не требуется.
