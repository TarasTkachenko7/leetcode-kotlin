# 0704. Binary Search

- **Сложность:** Easy
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №704](https://leetcode.com/problems/binary-search/)

## Идея
Для поиска элемента в отсортированном по возрастанию массиве применяется классический алгоритм двоичного поиска:
1. Инициализируем указатели границ поиска: `left = 0` и `right = nums.lastIndex`.
2. Пока `left <= right`:
    - Находим индекс середины диапазона: `mid = left + (right - left) / 2` (предотвращает целочисленное переполнение).
    - Если `nums[mid] == target`, элемент найден — возвращаем `mid`.
    - Если `target > nums[mid]`, искомый элемент находится в правой половине — сдвигаем левую границу `left = mid + 1`.
    - Если `target < nums[mid]`, искомый элемент находится в левой половине — сдвигаем правую границу `right = mid - 1`.
3. Если границы сошлись и элемент не найден, возвращаем `-1`.

## Сложность
- **Time Complexity:** $O(\log N)$ — область поиска делится пополам на каждой итерации цикла.
- **Space Complexity:** $O(1)$ — используются только целочисленные указатели.
