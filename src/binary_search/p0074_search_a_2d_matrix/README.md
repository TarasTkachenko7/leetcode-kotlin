# 0074. Search a 2D Matrix

- **Сложность:** Medium
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №74](https://leetcode.com/problems/search-a-2d-matrix/)

## Идея
Матрица размера $M \times N$ обладает свойствами: каждая строка отсортирована по возрастанию, а первый элемент каждой строки строго больше последнего элемента предыдущей строки:
1. **Поиск строки:**
    - Запускаем бинарный поиск по строкам: проверяем границы `matrix[mid][0]` и `matrix[mid].lastIndex`.
    - Если `matrix[mid][0] <= target <= matrix[mid].last()`, целевое значение может находиться только в этой строке — переходим к поиску внутри нее.
    - Если `matrix[mid][0] > target`, искомая строка находится выше: `rightMatrix = mid - 1`.
    - Иначе строка находится ниже: `leftMatrix = mid + 1`.
2. **Поиск внутри строки:**
    - Запускаем стандартный бинарный поиск по одномерному массиву `matrix[mid]` за $O(\log N)$.
3. Если подходящая строка не найдена или элемент в строке отсутствует, возвращаем `false`.

## Сложность
- **Time Complexity:** $O(\log M + \log N) = O(\log(M \cdot N))$, где $M$ — количество строк, а $N$ — количество столбцов.
- **Space Complexity:** $O(1)$ — дополнительная память константна.
