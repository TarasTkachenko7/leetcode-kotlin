# 0162. Find Peak Element

- **Сложность:** Medium
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №162](https://leetcode.com/problems/find-peak-element/)

## Идея
Пиковый элемент строго больше своих непосредственных соседей. Массив не отсортирован, но условие $nums[i] \neq nums[i+1]$ и воображаемые границы $nums[-1] = nums[n] = -\infty$ позволяют применить бинарный поиск по градиенту:
1. Используем схождение границ `while (left < right)`. Так как `left < right`, индекс `mid = left + (right - left) / 2` гарантированно не равен `right`, следовательно `mid + 1` всегда находится в пределах массива.
2. Сравниваем `nums[mid]` и `nums[mid + 1]`:
    - Если `nums[mid] < nums[mid + 1]`, последовательность возрастает вправо. Так как за правым концом массива находится $-\infty$, в правой половине гарантированно есть хотя бы один локальный максимум — смещаем `left = mid + 1`.
    - Если `nums[mid] > nums[mid + 1]`, последовательность убывает. Значит, пик находится либо в текущей позиции `mid`, либо левее нее — сужаем `right = mid`.
3. Цикл завершается при `left == right`, указывая на индекс локального пика. Возвращаем `left`.

## Сложность
- **Time Complexity:** $O(\log N)$ — область поиска делится пополам на каждом шаге.
- **Space Complexity:** $O(1)$ — дополнительная память константна.
