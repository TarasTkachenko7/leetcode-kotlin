# 0035. Search Insert Position

- **Сложность:** Easy
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №35](https://leetcode.com/problems/search-insert-position/)

## Идея
Для поиска индекса существующего элемента или определения корректной позиции вставки в отсортированном массиве используется бинарный поиск:
1. Инициализируем границы поиска: `left = 0` и `right = nums.lastIndex`.
2. В цикле `while (left <= right)`:
    - Вычисляем индекс середины: `mid = left + (right - left) / 2`.
    - Если `nums[mid] == target`, элемент найден — возвращаем `mid`.
    - Если `target > nums[mid]`, сдвигаем левую границу вправо: `left = mid + 1`.
    - Если `target < nums[mid]`, сдвигаем правую границу влево: `right = mid - 1`.
3. Если точное совпадение не обнаружено, цикл завершается при условии `left > right`. Указатель `left` гарантированно указывает на наименьший индекс элемента, который больше `target` (либо на позицию за пределами массива `nums.size`, если `target` превышает все элементы). Возвращаем `left`.

## Сложность
- **Time Complexity:** $O(\log N)$ — диапазон поиска делится пополам на каждой итерации.
- **Space Complexity:** $O(1)$ — используются только константные числовые переменные.
