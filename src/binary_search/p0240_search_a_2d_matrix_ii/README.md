# 0240. Search a 2D Matrix II

- **Сложность:** Medium
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №240](https://leetcode.com/problems/search-a-2d-matrix-ii/)

## Идея
Строки отсортированы слева направо, а столбцы — сверху вниз. Для линейного поиска используется свойство угловых элементов с противоположной монотонностью (верхний правый `(0, N - 1)` или нижний левый `(M - 1, 0)`):
1. Начинаем обход из правого верхнего угла матрицы: `row = 0`, `col = matrix[0].lastIndex`.
2. В цикле `while (row < matrix.size && col >= 0)`:
    - Если `matrix[row][col] == target`, значение найдено — возвращаем `true`.
    - Если `target < matrix[row][col]`, все элементы ниже в текущем столбце также будут строго больше `target`. Исключаем весь столбец: `col--`.
    - Если `target > matrix[row][col]`, все элементы левее в текущей строке также будут строго меньше `target`. Исключаем всю строку: `row++`.
3. Если указатели вышли за пределы матрицы, целевой элемент отсутствует — возвращаем `false`.

## Сложность
- **Time Complexity:** $O(M + N)$ — на каждом шаге указатель либо сдвигается на одну строку вниз, либо на один столбец влево, делая максимум $M + N$ итераций.
- **Space Complexity:** $O(1)$ — дополнительная память константна.
