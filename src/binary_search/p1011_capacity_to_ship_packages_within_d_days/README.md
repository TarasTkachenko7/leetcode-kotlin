# 1011. Capacity To Ship Packages Within D Days

- **Сложность:** Medium
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №1011](https://leetcode.com/problems/capacity-to-ship-packages-within-d-days/)

## Идея
Задача нахождения минимальной грузоподъемности корабля $C$, позволяющей перевезти грузы строго в исходном порядке не более чем за $D$ дней:
1. **Диапазон поиска:**
    - Минимальная грузоподъемность `left = weights.max()`, так как неделимый максимальный груз должен поместиться на корабль.
    - Максимальная грузоподъемность `right = weights.sum()`, позволяющая перевезти все посылки за один рейс.
2. **Жадный предикат валидации:**
    - Для проверяемой грузоподъемности `mid` моделируем погрузку грузов по порядку.
    - Если добавление груза `weight` превышает `mid`, отправляем текущий корабль и начинаем следующий день: `shipsNeeded++`, `currentWeight = 0`.
    - Накапливаем вес: `currentWeight += weight`.
3. **Бинарный поиск:**
    - Если `shipsNeeded > days`, текущая грузоподъемность недостаточна: `left = mid + 1`.
    - Если `shipsNeeded <= days`, емкость допустима, сохраняем её как потенциальный ответ и ищем меньшую: `right = mid`.
4. Цикл сходится в точке минимально возможной вместимости `left == right`.

## Сложность
- **Time Complexity:** $O(N \log(\sum W - \max W))$, где $N$ — число грузов, а $\sum W$ — их суммарный вес. На каждом шаге бинарного поиска выполняется жадный линейный проход по массиву.
- **Space Complexity:** $O(1)$ — используются только целочисленные аккумуляторы.
