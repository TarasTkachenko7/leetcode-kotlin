# 0875. Koko Eating Bananas

- **Сложность:** Medium
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №875](https://leetcode.com/problems/koko-eating-bananas/)

## Идея
Задача сводится к поиску минимального целочисленного значения скорости $k \in [1, \max(\text{piles})]$, при котором суммарное время поедания всех кучек не превышает $h$:
1. **Монотонность функции времени:** Функция суммарного затраченного времени монотонно убывает с ростом скорости поедания $k$. Это позволяет использовать бинарный поиск по значению ответа.
2. **Диапазон поиска:**
    - Нижняя граница: `left = 1`.
    - Верхняя граница: `right = piles.max()`.
3. **Предикат проверки:**
    - Для текущей скорости `mid` вычисляем суммарные часы: на кучку размера $p$ уходит $\lceil p / mid \rceil$ часов, что вычисляется целочисленно как `(p + mid - 1L) / mid`.
    - Суммируем часы в переменную типа `Long` во избежание переполнения.
4. **Сужение границ:**
    - Если `count > h`, скорость недостаточна — сдвигаем левую границу: `left = mid + 1`.
    - Если `count <= h`, скорость допустима, но может существовать меньшая — сохраняем текущую скорость в кандидатах: `right = mid`.
5. По завершении цикла `left == right` дает минимальную допустимую скорость.

## Сложность
- **Time Complexity:** $O(N \log M)$, где $N$ — количество кучек бананов (`piles.size`), а $M = \max(\text{piles})$ — размер максимальной кучки. Бинарный поиск делает $\log M$ шагов, и на каждом шаге выполняется линейный проход по массиву.
- **Space Complexity:** $O(1)$ — дополнительная память константна.
