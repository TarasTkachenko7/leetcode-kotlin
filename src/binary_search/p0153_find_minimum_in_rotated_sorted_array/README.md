# 0153. Find Minimum in Rotated Sorted Array

- **Сложность:** Medium
- **Паттерн:** Binary Search
- **Ссылка:** [LeetCode №153](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/)

## Идея
Массив отсортирован по возрастанию и циклически сдвинут на неизвестное число позиций. Все элементы уникальны:
1. Используем бинарный поиск с условием схождения `while (left < right)`.
2. На каждой итерации сравниваем средний элемент с крайним правым `nums[right]`:
    - Если `nums[mid] > nums[right]`: точка перегиба (минимальный элемент) находится строго в правой половине, так как порядок нарушен справа от середины. Смещаем левую границу: `left = mid + 1`.
    - Если `nums[mid] <= nums[right]`: отрезок от `mid` до `right` монотонно возрастает, следовательно, наименьший элемент либо равен `nums[mid]`, либо находится левее. Сужаем правую границу: `right = mid`.
3. По завершении цикла `left == right`, и указатель указывает непосредственно на наименьший элемент массива. Возвращаем `nums[left]`.

## Сложность
- **Time Complexity:** $O(\log N)$ — область поиска сокращается вдвое на каждой итерации.
- **Space Complexity:** $O(1)$ — используются только переменные индексов.
