# 1047. Remove All Adjacent Duplicates In String

- **Сложность:** Easy
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №1047](https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string/)

## Идея
Для последовательного удаления смежных одинаковых символов (включая образующиеся после схлопывания) применяется стек:
1. Инициализируем стек `ArrayDeque<Char>()`.
2. Последовательно перебираем символы строки `s`:
    - Если стек не пуст и символ на вершине равен текущему (`stack.last() == ch`), мы нашли пару соседних дубликатов — удаляем верхний символ из стека через `stack.removeLast()`.
    - В противном случае помещаем текущий символ в стек: `stack.addLast(ch)`.
3. Собираем оставшиеся в стеке символы в строку с помощью `joinToString("")`.

## Сложность
- **Time Complexity:** $O(N)$ — один проход по строке длины $N$, операции добавления/удаления из `ArrayDeque` выполняются за $O(1)$, построение результирующей строки занимает $O(N)$.
- **Space Complexity:** $O(N)$ — в худшем случае (когда все символы уникальны) стек будет содержать всю строку $s$.
