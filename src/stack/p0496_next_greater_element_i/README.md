# 0496. Next Greater Element I

- **Сложность:** Easy
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №496](https://leetcode.com/problems/next-greater-element-i/)

## Идея
Так как все элементы в `nums2` уникальны, а `nums1` является его подмножеством, задача сводится к предварительному вычислению следующего большего элемента для всех чисел из `nums2`:
1. Используем убывающий монотонический стек `ArrayDeque<Int>()` и словарь `map = HashMap<Int, Int>()`.
2. Проходим по `nums2`:
    - Пока стек не пуст и текущее число `num` строго больше числа на вершине стека `stack.last()`:
        - Снимаем вершину: `smallerNum = stack.removeLast()`.
        - Фиксируем в `map[smallerNum] = num`, так как `num` является первым большим элементом справа для `smallerNum`.
    - Добавляем текущий `num` в стек.
3. Формируем массив ответов для `nums1`: для каждого элемента берем значение из таблицы через `map.getOrDefault(currentNum, -1)`.

## Сложность
- **Time Complexity:** $O(N_1 + N_2)$ — каждый элемент `nums2` попадает в стек и извлекается не более одного раза ($O(N_2)$), после чего выполняется один линейный проход по `nums1` с запросами к `map` за $O(1)$ ($O(N_1)$).
- **Space Complexity:** $O(N_2)$ — память для хранения элементов в стеке и отображений в `HashMap`.
