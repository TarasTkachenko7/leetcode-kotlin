# 0232. Implement Queue using Stacks

- **Сложность:** Easy
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №232](https://leetcode.com/problems/implement-queue-using-stacks/)

## Идея
Для моделирования очереди (FIFO) с помощью стеков (LIFO) используются два стека: `inStack` (входной) и `outStack` (выходной):
1. `push(x)`: Все новые элементы помещаются в `inStack` за $O(1)$.
2. `pop()` и `peek()`:
    - Если стек `outStack` пуст, переносим в него все элементы из `inStack`, снимая их сверху (`removeLast()`) и помещая в `outStack` (`addLast()`). Это обращает порядок элементов на противоположный, превращая LIFO в правильный FIFO порядок.
    - Если в `outStack` уже есть элементы, они сразу готовы к извлечению с вершины.
3. `empty()`: Очередь пуста тогда и только тогда, когда оба стека (`inStack` и `outStack`) пусты.

## Сложность
- **Time Complexity:**
    - `push`: $O(1)$.
    - `pop`: $O(1)$ амортизированное (каждый элемент попадает в `inStack`, один раз переносится в `outStack` и один раз извлекается).
    - `peek`: $O(1)$ амортизированное.
    - `empty`: $O(1)$.
- **Space Complexity:** $O(N)$ — суммарно в двух стеках хранится не более $N$ элементов очереди.
