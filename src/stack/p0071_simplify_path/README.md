# 0071. Simplify Path

- **Сложность:** Medium
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №71](https://leetcode.com/problems/simplify-path/)

## Идея
Для канонизации абсолютного Unix-пути необходимо последовательно обработать компоненты между слэшами, учитывая правила перехода по директориям:
1. Разбиваем путь по разделителю `/` через `path.split("/")`.
2. Проходим по каждому компоненту `part`:
    - Если компонент пустой (результат множественных подряд идущих слэшей `//`) или равен `"."` (текущая директория), пропускаем его (`continue`).
    - Если компонент равен `".."` (переход на уровень выше), удаляем последнюю добавленную директорию со стека: `if (stack.isNotEmpty()) stack.removeLast()`. Если стек уже пуст, мы находимся в корне, переход выше невозможен — ничего не делаем.
    - Любое другое строковое значение считается именем директории и помещается на вершину стека: `stack.addLast(part)`.
3. Собираем канонический путь: объединяем элементы стека через `/` и добавляем ведущий слэш `"/" + stack.joinToString("/")`.

## Сложность
- **Time Complexity:** $O(N)$ — разбиение строки длины $N$, обработка компонентов в стеке и финальная конкатенация выполняются за линейное время.
- **Space Complexity:** $O(N)$ — память для хранения списка фрагментов пути и элементов в стеке.
