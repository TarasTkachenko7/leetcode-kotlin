# 0020. Valid Parentheses

- **Сложность:** Easy
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №20](https://leetcode.com/problems/valid-parentheses/)

## Идея
Для валидации правильности скобочной последовательности используется структура данных **Стек** (LIFO):
1. Создаем таблицу соответствия открывающей скобки закрывающей `map`.
2. Проходим по каждому символу строки `s`:
    - Если символ является открывающей скобкой (`i in map`), помещаем его на вершину стека: `stack.addLast(i)`.
    - Если символ — закрывающая скобка:
        - Проверяем стек на пустоту: если он пуст, значит, нет парной открывающей скобки — возвращаем `false`.
        - Снимаем верхний элемент со стека (`stack.removeLast()`) и сверяем его соответствие через `map[prev]`. При несовпадении возвращаем `false`.
3. После завершения прохода строка валидна тогда и только тогда, когда стек полностью пуст (`stack.isEmpty()`).

## Сложность
- **Time Complexity:** $O(N)$ — однократный проход по строке длины $N$, операции со стеком и `map` занимают $O(1)$.
- **Space Complexity:** $O(N)$ — в худшем случае (например, при строке из одних открывающих скобок) стек будет содержать все $N$ символов.
