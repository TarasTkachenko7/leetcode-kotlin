# 0933. Number of Recent Calls

- **Сложность:** Easy
- **Паттерн:** Queue
- **Ссылка:** [LeetCode №933](https://leetcode.com/problems/number-of-recent-calls/)

## Идея
Задача моделирует подсчёт запросов в скользящем временном окне $[t - 3000, t]$:
1. По условию каждый последующий вызов `ping(t)` имеет строго большее значение времени $t$, чем предыдущий.
2. Используем очередь с дисциплиной FIFO (`ArrayDeque<Int>()`).
3. При каждом вызове:
    - Добавляем текущее время в конец очереди: `queue.addLast(t)`.
    - Проверяем элементы в начале очереди (`queue.first()`): пока время запроса строго меньше `t - 3000`, извлекаем его через `queue.removeFirst()`.
4. Оставшиеся в очереди элементы точно попадают в требуемый интервал. Возвращаем `queue.size`.

## Сложность
- **Time Complexity:** $O(1)$ амортизированное на один вызов `ping`. Каждый элемент добавляется в очередь ровно один раз и удаляется из неё не более одного раза.
- **Space Complexity:** $O(W)$, где $W \le 3000$ — максимальное число запросов, способных уместиться во временном окне 3000 мс.
