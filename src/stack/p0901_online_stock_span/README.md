# 0901. Online Stock Span

- **Сложность:** Medium
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №901](https://leetcode.com/problems/online-stock-span/)

## Идея
Для нахождения количества последовательных предшествующих дней, в течение которых цена акции была меньше или равна текущей цене, используется монотонический стек пар `(цена, размах)`:
1. Инициализируем `span = 1` для текущего дня.
2. В стеке поддерживаем цены в строго убывающем порядке.
3. Пока стек не пуст и цена на вершине стека меньше либо равна новой цене (`stack.last().first <= price`):
    - Извлекаем пару `(_, prevSpan) = stack.removeLast()`.
    - Аккумулируем размах: `span += prevSpan`. Это позволяет перепрыгивать через уже схлопнутые диапазоны за один шаг без поштучного перебора дней.
4. Помещаем текущую цену и суммарный размах в стек: `stack.addLast(Pair(price, span))`.
5. Возвращаем вычисленный `span`.

## Сложность
- **Time Complexity:** $O(1)$ амортизированное на каждый вызов `next()`. Каждый элемент добавляется в стек ровно один раз и удаляется из него не более одного раза за всё время работы.
- **Space Complexity:** $O(N)$ — в худшем случае (при монотонно убывающем потоке цен) в стеке сохранятся все $N$ цен.
