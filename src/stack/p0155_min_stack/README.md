# 0155. Min Stack

- **Сложность:** Medium
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №155](https://leetcode.com/problems/min-stack/)

## Идея
Для получения минимума за константное время $O(1)$ необходимо отслеживать минимум для каждого состояния стека:
1. Создаем внутренний класс `Element(val value: Int, val min: Int)`, где поле `min` хранит минимальное значение среди всех элементов от дна стека до текущего уровня включительно.
2. При вызове `push(value)`:
    - Если стек пуст, текущее значение и является минимумом: `Element(value, value)`.
    - Если стек не пуст, вычисляем новый минимум как `minOf(value, stack.last().min)` и сохраняем новый узел.
3. При вызове `pop()` просто удаляем вершину стека (`stack.removeLast()`), при этом состояние минимума автоматически откатывается к предыдущему.
4. `top()` возвращает `stack.last().value`, а `getMin()` возвращает `stack.last().min` за $O(1)$.

## Сложность
- **Time Complexity:** $O(1)$ для всех методов (`push`, `pop`, `top`, `getMin`).
- **Space Complexity:** $O(N)$ — на каждый элемент сохраняется дополнительное поле минимума.
