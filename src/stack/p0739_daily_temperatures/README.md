# 0739. Daily Temperatures

- **Сложность:** Medium
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №739](https://leetcode.com/problems/daily-temperatures/)

## Идея
Для поиска следующего большего элемента (Next Greater Element) применяется убывающий монотонический стек:
1. Создаем результирующий массив `answer` размера `temperatures.size`, изначально заполненный нулями.
2. В стеке `stack = ArrayDeque<Int>()` храним индексы температур, упорядоченных по невозрастанию значений.
3. Проходим по массиву с текущим индексом `index`:
    - Пока стек не пуст и текущая температура `temperatures[index]` строго превышает температуру на вершине стека `temperatures[stack.last()]`:
        - Снимаем индекс с вершины: `prevIndex = stack.removeLast()`.
        - Записываем в результат разность индексов: `answer[prevIndex] = index - prevIndex`.
    - Помещаем текущий индекс в стек: `stack.addLast(index)`.
4. Индексы, оставшиеся в стеке к концу обхода, не имеют более тёплого дня справа и остаются со значением `0`.

## Сложность
- **Time Complexity:** $O(N)$ — каждый индекс помещается в стек ровно один раз и извлекается из него максимум один раз.
- **Space Complexity:** $O(N)$ — в худшем случае (при строго убывающих температурах) стек вмещает до $N$ индексов.
