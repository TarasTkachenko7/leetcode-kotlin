# 2390. Removing Stars From a String

- **Сложность:** Medium
- **Паттерн:** Stack
- **Ссылка:** [LeetCode №2390](https://leetcode.com/problems/removing-stars-from-a-string/)

## Идея
Символ `*` выполняет роль клавиши `Backspace`: он удаляет ближайший незвёздный символ слева от себя. Для поддержания такого порядка идеально подходит стек:
1. Инициализируем стек `ArrayDeque<Char>()`.
2. Последовательно обходим строку `s`:
    - Если встретился символ `*`, удаляем последний добавленный символ с вершины стека: `stack.removeLast()`.
    - В противном случае помещаем текущий символ в стек: `stack.addLast(i)`.
3. Собираем оставшиеся в стеке символы в итоговую строку через `joinToString("")`.

## Сложность
- **Time Complexity:** $O(N)$ — один проход по строке длины $N$, добавление и удаление из `ArrayDeque` выполняются за $O(1)$, сборка результирующей строки занимает $O(N)$.
- **Space Complexity:** $O(N)$ — в худшем случае (когда звёздочек нет) стек вмещает все $N$ символов входной строки.
