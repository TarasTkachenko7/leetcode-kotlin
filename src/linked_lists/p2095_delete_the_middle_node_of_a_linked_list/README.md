# 2095. Delete the Middle Node of a Linked List

- **Сложность:** Medium
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №2095](https://leetcode.com/problems/delete-the-middle-node-of-a-linked-list/)

## Идея
Для удаления узла из односвязного списка необходимо получить ссылку на узел, стоящий **перед** удаляемым.
1. Краевой случай: если список состоит из одного узла (`head.next == null`), средний узел — это сам `head`, возвращаем `null`.
2. Запускаем указатель `fast` с опережением на 2 шага (`head.next.next`), а `slow` — из `head`.
3. Двигаем `slow` на 1 шаг, а `fast` на 2 шага, пока `fast` и `fast.next` не станут `null`.
4. В момент остановки `slow` будет указывать ровно на элемент, предшествующий середине.
5. Исключаем средний узел: `slow.next = slow.next.next`.

## Сложность
- **Time Complexity:** $O(N)$ — однократный проход по списку ($N/2$ итераций).
- **Space Complexity:** $O(1)$ — дополнительная память не выделяется, операция выполняется на месте.
