# 0092. Reverse Linked List II

- **Сложность:** Medium
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №92](https://leetcode.com/problems/reverse-linked-list-ii/)

## Идея
Задача требует развернуть только часть списка от позиции `left` до `right` за один проход.
1. **Подготовка:** Создаем узел `dummy`, указывающий на `head`, чтобы легко обработать случай, когда `left == 1` (разворот от самого начала).
2. **Поиск границ:** Находим узел, стоящий строго перед началом разворачиваемой части — `nodeBeforeLeft`. Узел, следующий за ним (`curr`), станет хвостом развернутой части (`leftNode`).
3. **Разворот:** Стандартным циклом разворачиваем ровно `right - left + 1` узлов, используя указатели `prev`, `curr` и `nextTemp`.
4. **Переподключение:** После цикла `curr` указывает на первый узел после развернутой части, а `prev` — на новую голову развернутой части.
    - Подключаем конец развернутой части к остатку списка: `leftNode.next = curr`.
    - Подключаем начало развернутой части к предшествующему узлу: `nodeBeforeLeft.next = prev`.

## Сложность
- **Time Complexity:** $O(N)$ — алгоритм делает строго один проход по списку, достигая максимум узла на позиции `right`.
- **Space Complexity:** $O(1)$ — дополнительная память не выделяется, перенаправляются лишь существующие ссылки на месте.
