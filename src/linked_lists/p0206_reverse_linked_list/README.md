# 0206. Reverse Linked List

- **Сложность:** Easy
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №206](https://leetcode.com/problems/reverse-linked-list/)

## Идея
Для разворота односвязного списка на месте за один проход используем три указателя:
1. `prev` (изначально `null`) — будущий следующий узел для текущего элемента.
2. `current` (изначально `head`) — узел, чью ссылку `next` мы разворачиваем.
3. `tmp` — временное сохранение ссылки на `current.next`, чтобы не потерять хвост списка перед перенаправлением указателя.

На каждом шаге:
- Запоминаем следующий узел: `tmp = current.next`.
- Разворачиваем стрелку: `current.next = prev`.
- Сдвигаем окно указателей вправо: `prev = current`, `current = tmp`.

Когда `current` станет `null`, указатель `prev` будет указывать на новую голову развёрнутого списка.

## Сложность
- **Time Complexity:** $O(N)$ — однократный проход по всем узлам списка.
- **Space Complexity:** $O(1)$ — разворот выполняется in-place без выделения дополнительной памяти.
