# 0023. Merge k Sorted Lists

- **Сложность:** Hard
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №23](https://leetcode.com/problems/merge-k-sorted-lists/)

## Идея
Последовательное слияние списков один за другим занимает $O(N \cdot K)$ времени, где $K$ — количество списков, а $N$ — суммарное число узлов во всех списках.
Применяем подход **«Разделяй и властвуй»**:
1. Разбиваем $K$ списков на пары и объединяем каждую пару функцией `mergeTwoLists`.
2. После первого раунда количество списков сокращается вдвое: с $K$ до $\lceil K / 2 \rceil$.
3. Повторяем раунды попарного объединения, пока не останется ровно один результирующий список.
4. Высота дерева слияния составляет $\lceil \log_2 K \rceil$, а на каждом уровне суммарно обрабатываются все $N$ элементов.

## Сложность
- **Time Complexity:** $O(N \log K)$, где $K$ — число списков, $N$ — общее число узлов во всех списках.
- **Space Complexity:** $O(K)$ — память под временный список ссылок на головы списков на каждом шаге итерации. Слияние самих узлов происходит in-place.
