# 0083. Remove Duplicates from Sorted List

- **Сложность:** Easy
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №83](https://leetcode.com/problems/remove-duplicates-from-sorted-list/)

## Идея
Так как список уже отсортирован, одинаковые значения идут строго подряд.
1. Проходим по списку указателем `current`.
2. Сравниваем значение текущего узла со следующим: `current.`val` == current.next.`val.
3. Если значения совпадают, перенаправляем ссылку `current.next = current.next.next`, удаляя дубликат из цепочки. Указатель `current` на этом шаге не сдвигаем, чтобы проверить следующий узел на равенство тому же значению.
4. Если значения различаются, переходим к следующему узлу: `current = current.next`.

## Сложность
- **Time Complexity:** $O(N)$ — каждый узел связного списка проверяется один раз.
- **Space Complexity:** $O(1)$ — удаление происходит на месте перебросом ссылок без выделения дополнительной памяти.
