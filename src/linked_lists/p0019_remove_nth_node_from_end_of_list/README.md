# 0019. Remove Nth Node From End of List

- **Сложность:** Medium
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №19](https://leetcode.com/problems/remove-nth-node-from-end-of-list/)

## Идея
Для удаления $N$-го узла с конца за один проход необходимо позиционировать указатель на узел, стоящий непосредственно перед удаляемым:
1. Создаем фиктивный узел `dummy`, указывающий на `head`. Это защищает от особого случая, когда нужно удалить сам головной узел.
2. Инициализируем указатели `fast` и `slow` на `dummy`.
3. Сдвигаем `fast` вперед на $N + 1$ шагов, создавая фиксированное расстояние между указателями.
4. Двигаем оба указателя параллельно с шагом $1$, пока `fast` не выйдет за границы списка (`fast == null`).
5. Указатель `slow` окажется ровно перед узлом, подлежащим удалению. Перенаправляем ссылку: `slow.next = slow.next.next`.

## Сложность
- **Time Complexity:** $O(N)$, где $N$ — длина списка. Проход осуществляется ровно за один обход списка.
- **Space Complexity:** $O(1)$ — выделяется единственный вспомогательный узел `dummy`.
