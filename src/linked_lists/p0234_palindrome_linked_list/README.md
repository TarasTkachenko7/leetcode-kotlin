# 0234. Palindrome Linked List

- **Сложность:** Easy
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №234](https://leetcode.com/problems/palindrome-linked-list/)

## Идея
Проверка на палиндром за $O(1)$ по памяти выполняется в три шага:
1. **Поиск середины:** запускаем указатели `slow` (1 шаг) и `fast` (2 шага). По завершении цикла `slow` указывает на начало второй половины списка.
2. **Разворот второй половины:** разворачиваем узлы, начиная со `slow`, меняя указатели `next` на месте.
3. **Сравнение значений:** запускаем указатель `p1` с начала списка (`head`), а `p2` — с головы развернутой половины (`prev`). Сравниваем значения поэлементно до исчерпания второй половины (`p2 != null`).

## Сложность
- **Time Complexity:** $O(N)$ — три линейных прохода ($N/2$ для поиска середины, $N/2$ для разворота, $N/2$ для сравнения).
- **Space Complexity:** $O(1)$ — дополнительная память не выделяется, разворот происходит in-place.
