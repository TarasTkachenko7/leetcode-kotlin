# 0707. Design Linked List

- **Сложность:** Medium
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №707](https://leetcode.com/problems/design-linked-list/)

## Идея
Реализация базового односвязного списка с поддержкой операций доступа, вставки и удаления по индексу:
1. Храним ссылку на первый узел `head` и размер структуры `size`.
2. Валидация индексов: доступ и удаление допустимы в диапазоне `[0, size - 1]`, а вставка — в диапазоне `[0, size]`.
3. При вставке/удалении головы списка перенаправляем ссылку `head`.
4. Для операций в середине списка итерируемся до узла `index - 1` с помощью `repeat(index - 1)` и перенастраиваем указатели `next`.

## Сложность
- **Time Complexity:**
    - `get(index)`: $O(K)$, где $K$ — запрашиваемый индекс ($O(N)$ в худшем случае).
    - `addAtHead(val)`: $O(1)$.
    - `addAtTail(val)`: $O(N)$ для односвязного списка без указателя на `tail`.
    - `addAtIndex(index, val)`: $O(K)$ для поиска места вставки.
    - `deleteAtIndex(index)`: $O(K)$ для поиска предшествующего узла.
- **Space Complexity:** $O(N)$ — память пропорциональна количеству сохраненных элементов.
