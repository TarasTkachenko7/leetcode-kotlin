# 0876. Middle of the Linked List

- **Сложность:** Easy
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №876](https://leetcode.com/problems/middle-of-the-linked-list/)

## Идея
Для поиска середины связного списка за один проход без подсчёта общего размера используется паттерн медленного и быстрого указателей:
1. Запускаем указатели `slow` и `fast` из начала списка (`head`).
2. На каждой итерации `slow` смещается на $1$ шаг, а `fast` — на $2$ шага.
3. Когда `fast` достигает конца (`fast == null` или `fast.next == null`), указатель `slow` гарантированно указывает на середину списка.
4. При четном числе элементов алгоритм возвращает второй средний узел.

## Сложность
- **Time Complexity:** $O(N)$ — список обходится за один проход ($N/2$ итераций).
- **Space Complexity:** $O(1)$ — дополнительная память под структуры данных не выделяется.
