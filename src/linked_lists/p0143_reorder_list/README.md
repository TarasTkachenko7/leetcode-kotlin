# 0143. Reorder List

- **Сложность:** Medium
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №143](https://leetcode.com/problems/reorder-list/)

## Идея
Перестановка списка вида $L_0 \to L_n \to L_1 \to L_{n-1} \to \dots$ выполняется в три этапа:
1. **Поиск середины и разделение:** Находим середину списка с помощью медленного и быстрого указателей (`slow` и `fast`). Разрываем связь `slow.next = null`, получая две независимые половины.
2. **Разворот второй половины:** Разворачиваем вторую половину списка in-place с помощью трех указателей (`prev`, `curr`, `tmp`).
3. **Чередующееся слияние:** Поочередно объединяем элементы первой и второй половины, вплетая узел из второй части между узлами первой части.

## Сложность
- **Time Complexity:** $O(N)$ — линейный проход для поиска середины ($N/2$), разворот ($N/2$) и слияние ($N/2$).
- **Space Complexity:** $O(1)$ — преобразование выполняется на месте без выделения памяти под новые структуры данных.
