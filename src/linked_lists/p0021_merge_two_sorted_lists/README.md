# 0021. Merge Two Sorted Lists

- **Сложность:** Easy
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №21](https://leetcode.com/problems/merge-two-sorted-lists/)

## Идея
Слияние двух отсортированных связных списков выполняется аналогично фазе слияния в сортировке Merge Sort:
1. Создаем фиктивный узел `dummy`, чтобы сформировать новый список без дополнительных условий для первой ноды.
2. С помощью двух указателей `first` и `second` сравниваем текущие значения списков.
3. Меньший узел прикрепляем к `current.next` и сдвигаем соответствующий указатель вперед.
4. Когда один из списков исчерпан, оставшуюся непустую цепочку прикрепляем целиком за одну операцию: `current.next = first ?: second`.

## Сложность
- **Time Complexity:** $O(N + M)$, где $N$ и $M$ — длины исходных списков. Каждый узел просматривается не более одного раза.
- **Space Complexity:** $O(1)$ — новые узлы для элементов списков не создаются, перенаправляются лишь существующие ссылки `next`.
