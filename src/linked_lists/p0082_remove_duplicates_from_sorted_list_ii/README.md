# 0082. Remove Duplicates from Sorted List II

- **Сложность:** Medium
- **Паттерн:** Linked List
- **Ссылка:** [LeetCode №82](https://leetcode.com/problems/remove-duplicates-from-sorted-list-ii/)

## Идея
В отличие от задачи #83, при обнаружении одинаковых значений необходимо удалить **все** копии, включая сам исходный узел:
1. Создаем фиктивный узел `dummy`, ссылающийся на `head`. Это защищает случай, когда дубликаты находятся в самом начале списка.
2. `left` указывает на последний заведомо уникальный элемент.
3. `right` сканирует список. Если `right.val == right.next.val`, запускаем внутренний цикл `while`, чтобы пропустить всю последовательность одинаковых значений до последнего дубликата включительно.
4. Перенаправляем `left.next = right.next`, полностью исключая всю группу одинаковых узлов. Сам `left` не сдвигаем, так как следующий элемент тоже может оказаться дубликатом.
5. Если дубликатов у `right` не обнаружено, просто продвигаем `left = left.next`.

## Сложность
- **Time Complexity:** $O(N)$ — каждый узел списка обрабатывается не более двух раз (указателями `right` и `left`).
- **Space Complexity:** $O(1)$ — преобразование выполняется in-place.
