# 0209. Minimum Size Subarray Sum

- **Сложность:** Medium
- **Паттерн:** Sliding Window
- **Ссылка:** [LeetCode №209](https://leetcode.com/problems/minimum-size-subarray-sum/)

## Идея
Так как все числа в массиве строго положительные, сумма окна монотонно растет при расширении и убывает при сужении, что позволяет применить скользящее окно переменного размера (**Sliding Window**):
1. Инициализируем левую границу `left = 0`, текущую сумму `currentSum = 0` и минимальную длину `minLength = Int.MAX_VALUE`.
2. Расширяем окно вправо, добавляя `nums[right]` к `currentSum`.
3. Как только `currentSum >= target`:
    - Обновляем минимальную длину окна: `minLength = minOf(minLength, right - left + 1)`.
    - Сужаем окно слева, вычитая `nums[left]` из суммы и сдвигая `left++`, пока сумма остается не меньше `target`.
4. Если ни один подмассив не подошел под условие, возвращаем `0`, иначе возвращаем найденный `minLength`.

## Сложность
- **Time Complexity:** $O(N)$ — оба указателя `left` и `right` монотонно смещаются слева направо не более $N$ раз.
- **Space Complexity:** $O(1)$ — дополнительная память не выделяется.
