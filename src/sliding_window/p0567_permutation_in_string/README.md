# 0567. Permutation in String

- **Сложность:** Medium
- **Паттерн:** Sliding Window
- **Ссылка:** [LeetCode №567](https://leetcode.com/problems/permutation-in-string/)

## Идея
Строка $s_2$ содержит перестановку $s_1$ тогда и только тогда, когда в $s_2$ существует подстрока длины `s1.length` с точно такими же частотами символов:
1. Если `s1.length > s2.length`, перестановка заведомо не поместится — возвращаем `false`.
2. Подсчитываем частоты символов для первых `s1.length` символов в обоих массивах частот: `s1Count` и `s2Count`.
3. Заводим счетчик `matches` (от 0 до 26), показывающий количество символов латинского алфавита, чья частота в текущем окне точно совпадает с частотой в $s_1$. Если изначально `matches == 26`, возвращаем `true`.
4. Сдвигаем окно фиксированной длины `s1.length` по строке $s_2$:
    - **Включение нового символа справа (`rightChar`):** увеличиваем счетчик `s2Count[rightChar]`. Если частота сравнялась с `s1Count`, увеличиваем `matches++`; если до этого частота была равна и теперь превысила — уменьшаем `matches--`.
    - **Исключение старого символа слева (`leftChar`):** уменьшаем счетчик `s2Count[leftChar]`. Если частота сравнялась с целевой, инкрементируем `matches++`; если до этого частота была равна и теперь стала меньше — декрементируем `matches--`.
5. Если в любой момент `matches == 26`, найдена точная перестановка — возвращаем `true`.

## Сложность
- **Time Complexity:** $O(N)$, где $N$ — длина строки $s_2$. Инициализация окна занимает $O(\text{s1.length} + 26)$, а каждый сдвиг окна обрабатывается строго за $O(1)$ без полного сравнения массивов длины 26.
- **Space Complexity:** $O(1)$ — массивы частот имеют фиксированный размер 26 элементов.
