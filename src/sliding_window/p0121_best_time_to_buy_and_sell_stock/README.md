# 0121. Best Time to Buy and Sell Stock

- **Сложность:** Easy
- **Паттерн:** Two Pointers / Greedy
- **Ссылка:** [LeetCode №121](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)

## Идея
Для поиска максимальной прибыли от одной покупки и одной продажи акции за один проход:
1. Инициализируем переменную `bestProfit = 0` и минимальную цену `minPrice = Int.MAX_VALUE`.
2. Проходим по массиву цен с помощью указателя `right`:
    - Если текущая цена `prices[right]` меньше зафиксированного минимума `minPrice`, обновляем `minPrice` (находим более выгодную точку для покупки).
    - Вычисляем потенциальную прибыль от продажи по текущей цене `prices[right] - minPrice` и обновляем `bestProfit`, если она превышает текущий максимум.
3. По завершении цикла возвращаем `bestProfit`.

## Сложность
- **Time Complexity:** $O(N)$ — один линейный проход по массиву цен.
- **Space Complexity:** $O(1)$ — используются только две скалярные переменные для хранения состояния.
