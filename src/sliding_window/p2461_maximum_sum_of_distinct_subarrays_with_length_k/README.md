# 2461. Maximum Sum of Distinct Subarrays With Length K

- **Сложность:** Medium
- **Паттерн:** Sliding Window
- **Ссылка:** [LeetCode №2461](https://leetcode.com/problems/maximum-sum-of-distinct-subarrays-with-length-k/)

## Идея
Необходимо найти непрерывный подмассив строго длины $k$, состоящий исключительно из уникальных элементов, с максимальной суммой:
1. Используем скользящее окно с указателями `left` и `right`, `HashSet` для отслеживания уникальности и переменные `Long` для аккумулирования суммы без переполнения.
2. **Устранение дубликатов:** Перед добавлением `num = nums[right]` проверяем `set.contains(num)`. Если элемент уже внутри окна, сдвигаем `left` вправо, удаляя элементы из `set` и вычитая их из `currentSum`, пока дубликат не покинет окно.
3. Добавляем `num` в `set` и прибавляем к `currentSum`.
4. **Контроль размера окна:** Когда `set.size == k`, подмассив валиден:
    - Обновляем `maxSum = maxOf(maxSum, currentSum)`.
    - Сдвигаем левую границу на один шаг (`left++`), удаляя `nums[left]` из окна и множества для подготовки к следующей итерации.

## Сложность
- **Time Complexity:** $O(N)$ — оба указателя `left` и `right` проходят по массиву слева направо не более одного раза, операции с `HashSet` выполняются в среднем за $O(1)$.
- **Space Complexity:** $O(k)$ — множество `set` хранит не более $k$ уникальных элементов одновременно.
