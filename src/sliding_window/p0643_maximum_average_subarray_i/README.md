# 0643. Maximum Average Subarray I

- **Сложность:** Easy
- **Паттерн:** Sliding Window
- **Ссылка:** [LeetCode №643](https://leetcode.com/problems/maximum-average-subarray-i/)

## Идея
Для поиска непрерывного подмассива длины $k$ с максимальным средним арифметическим достаточно найти подмассив длины $k$ с максимальной суммой:
1. Вычисляем сумму первых $k$ элементов, инициализируя начальное скользящее окно: `0 until k`.
2. Сохраняем начальную сумму как `maxSum`.
3. Сдвигаем окно вправо от индекса $k$ до `nums.lastIndex`:
    - На каждом шаге пересчитываем сумму за $O(1)$: добавляем вошедший элемент `nums[i]` и вычитаем вышедший `nums[i - k]`.
    - Обновляем глобальный максимум `maxSum = maxOf(maxSum, currentSum)`.
4. В конце возвращаем `maxSum / k`.

## Сложность
- **Time Complexity:** $O(N)$ — один линейный проход по массиву длины $N$.
- **Space Complexity:** $O(1)$ — используются только числовые переменные для отслеживания сумм.
