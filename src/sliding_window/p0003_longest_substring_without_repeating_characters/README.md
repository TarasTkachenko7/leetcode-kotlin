# 0003. Longest Substring Without Repeating Characters

- **Сложность:** Medium
- **Паттерн:** Sliding Window
- **Ссылка:** [LeetCode №3](https://leetcode.com/problems/longest-substring-without-repeating-characters/)

## Идея
Для поиска самой длинной подстроки без повторяющихся символов применяется скользящее окно переменного размера с отслеживанием символов через `HashSet`:
1. Поддерживаем окно $[left, right]$ и множество `set`, хранящее уникальные символы текущего окна.
2. Проходим по строке указателем `right`:
    - Если символ `s[right]` уже присутствует в `set`, окно содержит дубликат. Сдвигаем левую границу `left` вправо, удаляя `s[left]` из множества до тех пор, пока дубликат не будет исключен.
    - Добавляем `s[right]` в `set`.
    - Обновляем максимальную длину подстроки: `maxLength = maxOf(maxLength, right - left + 1)`.
3. По завершении обхода возвращаем `maxLength`.

## Сложность
- **Time Complexity:** $O(N)$ — оба указателя `left` и `right` монотонно смещаются слева направо не более $N$ раз; операции с `HashSet` выполняются в среднем за $O(1)$.
- **Space Complexity:** $O(\min(N, \Sigma))$ — размер `HashSet` ограничен размером алфавита символов $\Sigma$ (для ASCII/Unicode) и длиной строки $N$.
