# 0066. Plus One

- **Сложность:** Easy
- **Паттерн:** Array / Carry
- **Ссылка:** [LeetCode №66](https://leetcode.com/problems/plus-one/)

## Идея
Обходим массив цифр справа налево, начиная с младшего разряда:
1. Если текущая цифра меньше `9`, увеличиваем её на единицу и сразу возвращаем изменённый массив.
2. Если цифра равна `9`, заменяем её на `0` и продолжаем обход влево: перенос единицы обрабатывается на следующей итерации.
3. Если цикл завершился, все цифры были равны `9`. Создаём массив на один элемент длиннее, ставим `1` в начало; остальные элементы уже равны `0`.

## Сложность
- **Time Complexity:** $O(N)$ — в худшем случае проходим все `N` цифр.
- **Space Complexity:** $O(1)$ дополнительной памяти, если найдена цифра меньше `9`; $O(N)$ в случае, когда все цифры равны `9` и создаётся новый массив.
