# 0053. Maximum Subarray

- **Сложность:** Medium
- **Паттерн:** Kadane's Algorithm
- **Ссылка:** [LeetCode №53](https://leetcode.com/problems/maximum-subarray/)

## Идея
Начинаем с первого элемента массива. `currentSum` хранит максимальную сумму непустого подмассива, который заканчивается на текущем индексе, а `maxSum` хранит лучший результат за весь проход.

Для каждого следующего числа выбираем максимум из двух вариантов. Можно начать новый подмассив с этого числа или добавить его к лучшему подмассиву, который заканчивался на предыдущем индексе. Затем обновляем `maxSum`. Инициализация первым элементом позволяет корректно обработать массив из одних отрицательных чисел.

## Сложность
- **Time Complexity:** $O(n)$ за один проход по массиву.
- **Space Complexity:** $O(1)$ дополнительной памяти.
