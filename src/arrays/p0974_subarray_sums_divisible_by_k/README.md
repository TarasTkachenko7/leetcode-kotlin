# 0974. Subarray Sums Divisible by K

- **Сложность:** Medium
- **Паттерн:** Prefix Sum + HashMap
- **Ссылка:** [LeetCode №974](https://leetcode.com/problems/subarray-sums-divisible-by-k/)

## Идея
Ведём префиксную сумму `currentSum` и храним в `remainderCounts` частоты остатков предыдущих префиксов. Разность двух префиксных сумм с одинаковым остатком делится на `k`. Если оператор `%` вернул отрицательный остаток, прибавляем `k`, чтобы привести его к диапазону от `0` до `k - 1`.

Начальная запись `0 → 1` учитывает пустой префикс. На каждом шаге сначала прибавляем к ответу число подходящих предыдущих префиксов, затем записываем текущий остаток. Такой порядок учитывает только непустые подмассивы.

## Сложность
- **Time Complexity:** $O(n)$ в среднем за один проход с обращениями к хеш-таблице.
- **Space Complexity:** $O(\min(n, k))$ дополнительной памяти для частот остатков.
