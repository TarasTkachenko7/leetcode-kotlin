# 0724. Find Pivot Index

- **Сложность:** Easy
- **Паттерн:** Prefix Sum
- **Ссылка:** [LeetCode №724](https://leetcode.com/problems/find-pivot-index/)

## Идея
Первым проходом вычисляем `totalSum`. Во втором проходе прибавляем `nums[i]` к `currentSum`, чтобы получить сумму от начала массива до индекса `i` включительно.

Сумма строго слева равна `currentSum - nums[i]`, а сумма строго справа равна `totalSum - currentSum`. Сравниваем их на каждом шаге. Обход слева направо возвращает первый подходящий индекс. Если суммы нигде не совпали, возвращаем `-1`.

## Сложность
- **Time Complexity:** $O(n)$ за два прохода по массиву.
- **Space Complexity:** $O(1)$, поскольку храним только текущую и общую суммы и индекс.
